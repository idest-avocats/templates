# Cloud review – privatim fact sheet (V3.02)

This Excel file allows a Swiss cantonal public body to review a cloud project against each requirement of privatim's fact sheet on cloud-specific risks and measures (version 3.02 of 2 October 2026).

* 34 requirements, rephrased and linked to their source, with the corresponding excerpt from the fact sheet (unofficial translation), a qualification by id est avocats (legal requirement, good practice, beyond the law, disputed) and comments.
* Threshold questions determine which requirements apply to the project.
* The organisation documents the status, findings, choices and planned measures; results, a summary and a proposal are calculated automatically.
* The user guide is in the "References" tab.

**Download:** [English version](privatim-cloud-checklist-EN.xlsx) · [version française](privatim-cloud-checklist-FR.xlsx)
